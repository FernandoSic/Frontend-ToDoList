# To Do List

## Prerequisitos

Antes de comenzar, asegúrate de tener instalados los siguientes programas y herramientas:

1. **Node.js**: [Descargar e instalar Node.js](https://nodejs.org/)
2. **npm**: npm se instala automáticamente con Node.js. Verifica la instalación con:
   ```sh
   npm -v
   ```

## Pasos para su ejecución

1. **Clonar el repositorio**  
   ```sh
   git clone https://github.com/FernandoSic/Frontend-ToDoList.git
   ```

2. **Navegar a la dirección del proyecto**  
   ```sh
   cd Frontend-ToDoList
   ```
3. **Instalar las dependencias**  
   ```sh
   npm install
   ```

4. **Iniciar el servidor**  
   ```sh
   npm start
   ```

5. **Abre un navegador web y visita la siguiente dirección**
   ```
   http://localhost:3000 
   ```
